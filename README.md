# 🤖 Personal Deal & Apartment Hunter (Kyiv)

Персональный Telegram-бот для мониторинга супер-скидок, уценок и покупки квартир в Киеве.

## 🎯 Что мониторит система:
1. **🏠 Квартиры в Киеве (покупка до $40 000):**
   * **Только Правый берег:** Печерск, м. Лыбедская, Демеевка, Голосеево, ближняя Соломенка.
   * **Источники:** OLX.ua и Rieltor.ua.
   * **Анти-фейк фильтр:** Отсекаются первые взносы рассрочек, комнаты в коммуналках, цоколи, паркинги и весь Левый берег.
2. **🛒 Продукты и супермаркеты:**
   * Ашан (Лыбедская / Ocean Plaza), Сільпо («Ціна тижня»), Novus, Varus (уценка и недельные скидки).
3. **📦 Товары и быт:**
   * **Kasta.ua:** Корм для кошек, бытовая химия, кофе со скидками от 25-40%.
   * **MakeUp:** Уценка (ароматы для дома, парфюм, уход за лицом, бытовая химия без декоративной косметики).
4. **🍗 Фастфуд:**
   * **KFC:** Скидки ~50% (включая «Шалену середу»).
5. **⚡️ Хайп / Укр-тредс:**
   * Ценовые баги и вирусные акции.

## 🧠 Система обучения (Лайки и Дизлайки):
Под каждым сообщением в Telegram прикреплены кнопки:
* `👍 Выгодно` — бот запоминает, что товар/квартира вам понравились, и ищет больше похожего.
* `👎 Не интересно` — бот удаляет объект из рекомендаций, извлекает ключевые слова и **больше никогда не рекомендует подобное**.

## 🚀 Запуск:
```bash
# Активация виртуального окружения
source .venv/bin/activate

# Запуск ручного сканирования
python main.py

# Запуск фонового обработчика кнопок 👍/👎
python feedback_handler.py
```

## ☁️ Бесплатный запуск 24/7 (GitHub Actions):
В папке `.github/workflows/monitor.yml` уже настроен автоматический запуск каждый час через бесплатный GitHub Actions.
